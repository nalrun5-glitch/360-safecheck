# 360° SafeCheck

Прототип цифрового предрейсового кругового осмотра транспортных средств для АО «Каражанбасмунай».

## Что уже работает
- RU/KZ интерфейс
- идентификация ТС из QR-ссылки
- 6 последовательных зон 360°-осмотра
- фиксация дефекта и фото на мобильном устройстве
- отметка критического дефекта
- HARD STOP при критическом дефекте
- генератор QR на /qr

## Принцип
Не просто отметить выполнение осмотра, а цифрово подтвердить прохождение последовательных контрольных зон до начала движения.

## Следующий этап
Подключение Supabase: пользователи, парк ТС, журнал осмотров, хранение фото, кабинет контрольного механика, закрытие дефектов и аналитика.
